Proyecto de la asignatura Arquitectura de Sistemas Computacionales.
Aplicación web para la gestión y reserva de citas de una barbería.

## Descripción del proyecto

TurnoFácil es una aplicación web diseñada para solucionar los problemas que presenta una barbería al administrar sus citas por WhatsApp.

Actualmente, la gestión de citas puede depender de WhatsApp y Excel o agendas, lo que puede generar mensajes perdidos, citas cruzadas, olvidos y dificultades para cancelar una cita.

TurnoFácil busca convertir este proceso manual en un sistema organizado donde el cliente pueda gestionar directamente su turno.

El sistema permitirá que los clientes consulten los servicios, revisen las fechas y horarios disponibles, seleccionen un horario, registren una cita y puedan cancelarla cuando sea necesario.

## Problema

Actualmente, muchas barberías pueden manejar sus citas mediante WhatsApp. Este proceso puede generar problemas de organización y errores en la gestión de los horarios.

### Problemas principales

- Se pueden asignar dos clientes al mismo horario.
- El barbero puede olvidar una cita.
- El cliente puede olvidar la hora de su cita.
- Para cancelar, el cliente debe escribir nuevamente por WhatsApp.
- No existe una lista centralizada y organizada de las citas.
- El administrador debe revisar manualmente los mensajes.

## Solución inicial V1

La primera solución consiste en continuar utilizando WhatsApp junto con una agenda de papel o un archivo de Excel compartido.
